What is Strudel?

Web-based REPL for livecoding

based on the TidalCycles DSL

Part of the uzu family of languages

Huge in the Algorave scene

You only need a computer with a browser

strudel.cc

Wait back up a bit

Algorave?

Livecoding is not a new thing

It has roots both in the DIY electronic scene and academia

Music coding specifically goes all the way back to the 80s

The THX deep note is an early example

There are many languages and shells like
ChucK, SonicPi (Ruby), Tidal (Haskell) and ORCA.

Many environments also include real-time visual livecoding

Strudel includes Hydra

Livecoding is a sleeper hit

It's always been around but it used to be niche

The REPLs used to require installing and
configuring multiple pieces of software

E.g. Tidal needs Supecollider, Superdirt and a text editor

SonicPi simplified things with a single executable
and was the go-to livecoding tool for a while

Strudel is a game-changer

PWA running fully on the client-side

Uses both WebAudio and WebMIDI

Modular and embeddable!

Culture (the best part)

The livecoding community is STRONGLY anti-AI

It's basically a mirror universe of mainstream tech

The major names are women and/or LGBTQ+

Look up DJ_Dave, Switch Angel, Bbubu Sync, Glossing

All Uzu projects (including Strudel) are hosted on
Codeberg, which prohibits LLM contributions

Coding TL;DR

Notes and events use Tidal mini-notation

It's all about chaining functions

Like connecting cables in a modular synth or using pipes in a shell

$: marks an individual track/instrument

"_" mutes a track, "S" solos it

Plan your code to quickly comment/uncomment lines
