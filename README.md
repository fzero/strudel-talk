# Coding beats live with Strudel

Slides for the talk including strudel code.

Ths whole thing is in `index.html`. Either open it directly in the browser or run a local server in the root folder (e.g. `npx serve .`).

## Samples

The embedded strudel examples need strudel sampler running in `/samples`:

```sh
cd samples
npx @strudel/sampler
```

You can also load samples remotely with `samples('github:fzero/strudel-talk')` on the REPL.

You'll need NodeJS installed to make all of this work. Strudel itself is stand-alone though - just go to [strudel.cc](https://strudel.cc)
